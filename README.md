# TravelSchedule

Приложение «Расписание путешествий» для 20-го спринта. Интерфейс написан на SwiftUI; данные городов, станций и расписания загружаются из API Яндекс Расписаний. Минимальная версия — iOS 17.0, поддерживаются iPhone и портретная ориентация.

Реализованы заставка, выбор города и станции с поиском, список маршрутов, фильтры времени отправления и пересадок, общие экраны ошибок и информация о перевозчике с контактными ссылками. В настройках можно переключить светлую/тёмную тему независимо от системной; выбор сохраняется между запусками. Пользовательское соглашение открывается в WebView.

На главном экране размещена горизонтальная лента историй с локальными изображениями. Истории открываются с анимацией на весь экран, переключаются тапами, свайпами и автоматически каждые 10 секунд. Таймер Combine управляет прогрессом и приостанавливается при уходе приложения в фон. Закрыть просмотр можно крестиком или свайпом вниз; просмотренные превью отображаются без синей рамки и с уменьшенной яркостью.

## Запуск

1. Откройте `TravelSchedule.xcodeproj` и дождитесь загрузки пакетов. Если Xcode запросит разрешение для плагина `OpenAPIGenerator`, нажмите **Trust & Enable**.
2. Скопируйте `Configuration/Secrets.example.xcconfig` в `Configuration/Secrets.xcconfig` и укажите ключ API Яндекс Расписаний вместо `YOUR_API_KEY`. Локальный файл с ключом исключён из Git.
3. Выберите симулятор iPhone и запустите приложение.

## Примеры запросов

В **Product → Scheme → Edit Scheme → Run → Arguments** добавьте `-runAPIExamples` в **Arguments Passed On Launch**. Запустите Debug-сборку и откройте консоль Xcode.

В `APIExamples.swift` вызываются восемь сервисов: ближайшие станции, маршруты между городами, расписание станции, остановки рейса, ближайший город, перевозчик, список станций и копирайт. Для запроса остановок используется UID рейса из полученного расписания. Результат или сообщение об ошибке выводится отдельно для каждого запроса.

После проверки отключите аргумент запуска. Для работы выбора города и станции, а также поиска маршрутов, настройте локальный API-ключ по инструкции выше.
